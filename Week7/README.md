# Document Question Answering System (RAG)

## Overview

This project implements a Retrieval-Augmented Generation (RAG) system that answers questions from PDF documents.

Instead of relying only on an LLM, the system retrieves the most relevant document chunks and uses them as context for answer generation.

---

## Features

- Upload PDF
- Automatic text extraction
- Text chunking
- HuggingFace embeddings
- Chroma vector database
- Semantic search
- Google Gemini answer generation
- Streamlit interface

---

## Technologies

- Python
- Streamlit
- LangChain
- HuggingFace
- ChromaDB
- Gemini
